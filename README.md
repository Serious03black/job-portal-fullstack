## 🛠 Design & Technology Architecture
- **Structure**: Semantic HTML5 with accessibility tags and mobile-first responsive viewport.
- **Styling**: Tailored, modern CSS Design System in [`css/styles.css`](file:///d:/C%20Drive/pallavi%20project/css/styles.css) using CSS Custom Properties (Variables), glassmorphism cards, micro-animations, and responsive CSS Grid/Flexbox.
- **Interactivity**: Clean, dependency-free vanilla JavaScript handling:
  - Interactive search and multi-facet filtering on the Job Board.
  - Interactive Staffing and Payroll Cost Estimator.
  - One-click check-in/out attendance simulator on Employee Dashboard.
  - Modal application flows and CSV / PDF downloads.
  - Dynamic status toggling for Admin job postings and leave approvals.
